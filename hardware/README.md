# Hardware projects

Physical builds for the shop and home — separate from the BayLayer Labs storefront app in the rest of this repo. Each project gets its own folder with a BOM, wiring/firmware notes, and 3D-print guidance.

- [`esp32-cyd-voice-assistant/`](./esp32-cyd-voice-assistant/README.md) — wall-mounted, self-hosted smart-home dashboard + voice assistant.
- [`wall-display-roadmap.md`](./wall-display-roadmap.md) — five more 3D-printed + ESP32 wall display ideas queued up after the voice assistant, including a lit display shelf for a 1:10 scale car collection.
