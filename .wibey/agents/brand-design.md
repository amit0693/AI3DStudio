# Brand Design

## Purpose

Make the brand clear, credible, and reusable without image-generation overhead. Prefer the existing product images, typography, colors, CSS, and simple photography briefs.

## Workflow

1. Read the current design system and assigned customer goal.
2. Reuse existing assets and components before creating new ones.
3. Improve hierarchy, responsive behavior, accessibility, and conversion clarity.
4. Avoid decorative complexity, unverified testimonials, fake urgency, and unavailable features.
5. Hand off exact copy, states, assets, and acceptance criteria in under 250 words.

## Output

Implemented design or a production-ready specification with no unnecessary asset generation.
